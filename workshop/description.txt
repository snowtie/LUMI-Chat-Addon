[h1]LUMI Chat Addon[/h1]

LUMI Chat에 ChatGPT 계정, Claude 계정과 선택형 LUMI GPT-SoVITS 목소리를 추가하는 비공식 코드 플러그인입니다.

[b]STUDIO LUMI, LUMI Chat 제작자, OpenAI 또는 Anthropic의 공식 제품이 아닙니다.[/b]

[h2]필수 항목[/h2]
[url=https://steamcommunity.com/sharedfiles/filedetails/?id=3794360578]LUMI Chat[/url]

[h2]설치[/h2]
[list]
[*]LUMI Chat과 이 항목을 구독합니다.
[*]Little LUMI를 다시 시작합니다.
[*]트레이 또는 설정 → 모드에서 LUMI Chat Addon 설정을 엽니다.
[*]ChatGPT 또는 Claude 계정을 연결합니다.
[*]루미 AI 설정 → 두뇌에서 사용할 계정을 선택합니다.
[/list]

별도 설치기나 JAR 패치가 필요 없습니다. 앱 업데이트가 되어도 플러그인과 설정이 유지됩니다.

[h2]추가 기능[/h2]
[list]
[*]공식 Codex App Server를 이용한 ChatGPT 계정 연결
[*]공식 Claude Code를 이용한 Claude 계정 연결
[*]저사용량 GPT-5.6 Luna 기본 모델
[*]혼잣말과 화면 구경 기본 비활성화
[*]루미 AI 설정에 계정 프로바이더와 GPT-SoVITS 추가
[*]GPU 자동 호환 판정과 CPU 대체
[*]집중 모드 즉시 무음, 음성 절전 및 초절전
[*]Codex 작업 완료 말풍선 알림 MCP
[/list]

[h2]LUMI Chat 기능 유지[/h2]
대화창, 말풍선, 기억, 페르소나, 자동 동작, 캐릭터별 음성과 입 모양은 LUMI Chat의 기존 경로를 그대로 사용합니다.

[h2]선택형 GPT-SoVITS[/h2]
애드온 설정의 GPT-SoVITS 설치 또는 복구를 누르세요. 공식 통합판은 약 6~9GB, 허가된 LUMI 음성 가중치는 약 420MB입니다. 완료 문구가 나올 때까지 설치 창을 닫지 마세요.

ChatGPT 대화에는 계정의 Codex 사용량이, Claude 대화에는 계정의 Claude Code 사용량이 적용됩니다.
