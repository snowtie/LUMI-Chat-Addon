LUMI Chat Addon 1.1.2
=====================

This is an unofficial code plugin extension for LUMI Chat.

Requirements
1. Subscribe to LUMI Chat (Workshop ID 3794360578).
2. Subscribe to LUMI Chat Addon.
3. Restart Little LUMI.
4. Approve code execution and enable both mods in Mods settings. Restart if
   prompted, then open LUMI Chat Addon settings from the tray or Mods settings.
5. Connect a ChatGPT or Claude account.
6. Select the account provider in LUMI AI Settings > Brain.

Optional voice
Use GPT-SoVITS Install or Repair in the addon settings. Keep the setup window
open until the completion message appears. The official runtime is about
6-9GB and the authorized LUMI voice weights are about 420MB.

The plugin never replaces Shimeji-ee.jar or the LUMI Chat JAR. External helper
software is downloaded from the official project release and verified by
SHA-256. Codex App Server and Claude Code are installed from their official
publishers.

This project is not endorsed by STUDIO LUMI, the LUMI Chat author, OpenAI, or
Anthropic.
